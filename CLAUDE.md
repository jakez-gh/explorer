# Explorer — Development Context

## Project Overview
**Explorer** is a first-person flying exploration game in Unreal Engine 5.4. The feeling is **flying in a dream** through an endless, Earth-like world — procedurally generated, minimalist UI, pure discovery.

**Status:** Builds and runs. Endless streamed world with biomes, settlements and floating islands; dreamlike glide flight with banking; pause menu. Verified in-game with keyboard/mouse; gamepad untested.

## Game Pillars
1. **Flight** — Floaty, graceful first-person gliding (not walking); bank into turns
2. **Exploration** — The world changes with distance; places to discover if you fly far enough
3. **Immersion** — Minimal UI, golden-hour haze, soft bloom; dreamlike rather than realistic
4. **Scale** — Feeling small in a vast world

## Technical Direction
- **Engine:** Unreal Engine 5.4 (5.4.4), installed at `C:\Users\jake\UnrealEngine\UE_5.4` (not Program Files)
- **Toolchain:** VS 2022 Build Tools only (no IDE, MSVC 14.44) — build from the command line:
  `C:\Users\jake\UnrealEngine\UE_5.4\Engine\Build\BatchFiles\Build.bat ExplorerEditor Win64 Development -Project=<repo>\Explorer.uproject -WaitMutex`
  - Requires user env var `UE_SDKS_ROOT=C:\Users\jake\UnrealEngine\AutoSDK` (placeholder NETFXSDK so UBT resolves SwarmInterface; the real .NET Framework SDK isn't installed and needs admin)
  - `Explorer.Build.cs` defines `PLATFORM_HAS_ASAN_INCLUDE=0` and disables PCHs to work around UE 5.4 headers failing on MSVC 14.40+
  - Close the running game (and `CrashReportClient`) first, or linking fails on the locked DLL
- **Run:** `UnrealEditor.exe <repo>\Explorer.uproject -game -windowed -ResX=1600 -ResY=900` (map, game mode and input are set in `Config/`)
  - `-StartX= -StartY=` (world units) start anywhere; `-StartZ= -StartYaw= -StartPitch=` refine it
  - `-BiomeReport` logs the nearest location of each biome, village, city and floating island
  - `-FlightDebug` logs fps, altitude and velocity once a second
- **Assets:** No hand-made content. Materials are generated by `Tools/create_materials.py` (run via `UnrealEditor-Cmd.exe ... -run=pythonscript -script=...`); props use engine basic shapes with per-instance colours.

## Architecture
- `Procedural/WorldGen` — pure functions of world XY: height, climate (temperature/moisture), biome, ground colour, tree density. Continents ~40 km, climate zones ~20–35 km, mountain ranges, desert dunes/mesas, beaches. Sea level is Z=0.
- `Procedural/TerrainStreamer` — keeps a disc of 320 m chunks around the player: LOD rings (64→4 quads) with skirts, collision near, vertex-coloured terrain, ocean plane. Props via pooled HISMs: trees/cacti/boulders and villages near (detail radius), cities and floating islands everywhere in view. Landmark placement (`FindVillage/FindCity/FindFloatingIsland`) is shared with `-BiomeReport`.
- `Flight/FlightPawn` — glide model: throttle eases speed, velocity direction lags the view, bank from measured yaw rate, look-ahead ground cushion, FOV widens with speed, gentle camera bob. Input actions/mappings created in code.
- `Game/ExplorerGameMode` — spawns terrain and player (over land), strips the template map's sky sphere/floor, sets up the dream atmosphere (sun, fog, post-process).
- `Game/ExplorerPlayerController` — Escape/Start toggles a Slate pause menu (Resume/Quit); Alt+Q quits.

## Controls
- W/S or left stick Y: throttle (hover ↔ cruise ↔ fast) · A/D or left stick X: turn (banks)
- Mouse / right stick: look · E/Space, Q/Ctrl or triggers: up/down · Shift or bumpers: boost
- Escape: pause menu · Alt+Q: quit

## Known Decisions
- **No combat, no NPCs** (for now) — focus on pure exploration
- **First-person only** — no third-person view
- **Continuous flight** — no landing or walking; the ground gently pushes you away
- **Stylized, not photoreal** — primitive shapes and soft light suit the dream feel
